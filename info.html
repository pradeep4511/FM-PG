FM-PG / Project information

Find a better PG stay.

FM-PG is a React and Supabase application for discovering, browsing, and publishing paying guest accommodation listings.

What is included

  • Seeker and owner authentication flows
  • PG listing browsing and detail views
  • Owner listing submission form
  • Supabase-backed listings, images, and sharing options

Local development

Install dependencies and start the Vite development server:

npm install
npm run dev

Build the production bundle with npm run build.

Recommended Netlify deployment

  1. Push this project to a GitHub, GitLab, or Bitbucket repository.
  2. In Netlify, choose Add new site and then Import an existing project.
  3. Select the repository and use npm run build for the build command.
  4. Set the publish directory to dist, then deploy the site.
  5. In Netlify site settings, add the same Supabase environment variables used by src/lib/supabase.js.

Netlify will automatically rebuild the site whenever changes are pushed to the selected branch. The current Vite configuration does not need a special Netlify adapter.

Before going live

  • Confirm the Supabase URL and anonymous key are configured as Netlify environment variables.
  • Check Supabase authentication redirect URLs and add the deployed Netlify domain.
  • Verify database row-level security policies for reading and creating listings.
  • Run npm run build locally once to catch production build errors.
